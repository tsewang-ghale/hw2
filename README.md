# 🎶 K-Pop Library – Final Project  

## 📌 Project Overview  
The **K-Pop Library** is a full-stack web application designed to manage and explore data about K-Pop idol groups, songs, companies, and awards.  
It allows users to view, search, add, edit, and delete records while also providing visual insights through interactive charts.  

🔗 **Live Website:** [K-Pop Library](https://finalproject.tsewangghale.oucreate.com/index.php)  

---

## 🚀 Features  
- **Dynamic Database Integration:** Built with PHP and MySQL to manage K-Pop data.  
- **CRUD Operations:** Add, edit, and delete records for idol groups, songs, companies, and awards.  
- **Search & Filter:** Users can search records by category (songs, idol groups, companies, awards).  
- **Data Visualization:** Implemented interactive bar charts with Chart.js to display:  
  - Top idol groups with the highest number of awards.  
  - Number of songs released by each idol group.  
- **Responsive UI:** Designed with Bootstrap and custom styling for accessibility and usability.  
- **Background Slideshow:** Added animated backgrounds for a modern aesthetic.  
- **Deployment:** Hosted on OU Create with GitHub version control.
